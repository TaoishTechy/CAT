## 4. Anchors, confidence, and statistics

**Ranks.** Closed enum: `tpm2`, `se`, `strongbox`, `tpm-hat`, `trng-flash`, `vtpm`. `vtpm` MUST price strictly worse than `tpm2` by the term-sheet margin. Self-pairs are reported separately and do not count toward the 20 directed cross-pairs.

**C_S.** Compression ratio keeps the name `C_S`. The promotion confidence gate is `conf_omega`, with a named estimator. The bare threshold 0.8 is not a conjunct until that estimator is locked. “Sophia” is deleted from the series.

**Power.** T3.6’s normal approximation is a planning formula. Gates at small k use a pre-registered exact or bootstrap test. A metric without `{k, α, power, coverage}` cannot confer promotion.

**100% language.** G6, T3.8, and chaos vetoes report N and a rule-of-three or SPRT bound. A flat “100%” with no N is a schema failure.

**Cadence.** D_impl series publish monthly. Epoch publication of the current value remains. The monthly row is the audit artifact.

§4.7 step 2 is replaced: a vTPM gap miss causes re-measurement and an erratum against the published gap. Adjusting the published ε to meet the gate before the drill is a named metric-gaming class and fails the honesty audit.

Consent-chain order is Android → Mini → Linux witness → Windows witness → macOS witness, because that is the attestation path of the scenario, not a trust ranking. Each hop has an A4 bound. An end-to-end signature covers the chain.

Endpoint compromise is visible only for events the endpoint still reports. Plaintext exfiltration after key release is not claimed visible. The ledger bounds handles; it does not see the host.

Expired predictions with no data record `UNDETERMINED`, which is not a violation. A violated prediction records `FALSIFIED`.
